# Swipe Keyboard trained models, 2026-10-23

Models trained and released by Destin Moss via youcoded.ai, 2026.
SPDX-FileCopyrightText: 2026 Destin Moss <https://youcoded.ai>

Four neural next-word models (English, Spanish, French, German) and one swipe-recognition model. They sit beside the
language files published in release `language-files-2026-10-22-open-words` and are checked by SHA-256 against
`packaging/assets.lock.json` in github.com/itsdestin/swipe-keyboard before use. A missing or damaged file only turns
that model off (suggestions fall back to the n-gram files; swipes fall back to the geometric matcher); it never
disables a language.

| File | What it is | Declared licence |
|---|---|---|
| `LANG.nwp.bin` (en, es, fr, de) | next-word model: a small recurrent network (one LSTM layer, integer weights, about 4.7 MB), used together with `LANG.ngram` | ODC-By-1.0 AND CC-BY-2.0-FR |
| `swipe-model.bin` | swipe recognition: small convolution + recurrent network (about 0.5 million weights, 2.1 MB) shared by all four languages | MIT |

## How they were built

Scripts in github.com/itsdestin/swipe-keyboard (commit `14f9722` and its ancestors on branch `feature/179-engine-in-keyboard`):

- Next-word models: `scripts/lm/nwp/prepare.py` (tokenise, vocabulary), `train.py` (train), `tune.py` (blend with the
  n-gram), `export.py` (write `LANG.nwp.bin`). Training text: the same FineWeb (English, sample-10BT) / FineWeb-2
  (Spanish, French, German) text and Tatoeba sentences as the n-gram files, with test sentences held out (Tatoeba ids
  ending in 0, and sentences sharing an 8-word run with the test sets).
- Swipe model: `scripts/swipe/prep_data.py`, `assemble_futo.py`, `synth_swipes.py`, `train.py`. Training data: real
  swipes from FUTO's swipe.futo.org dataset (MIT) plus synthetic swipes generated from our open word lists
  (our own noise model, no FUTO code or model weights). Sessions used for validation or final scoring were held out.
