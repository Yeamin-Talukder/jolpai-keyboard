## Jolpai Keyboard 0.9.0 beta: smarter spelling fixes, a new About page 🫒

### ⚠️ Coming from 0.7.0 or 0.8.0? Move your data once
Jolpai has a new app ID, **`com.yeamin.jolpai`** (it was `com.yeamin.lipi`), so Android installs 0.9.0
as a **new app** next to the old one instead of updating it. To keep your words, settings, snippets and themes:
1. In the **old** app: **Backup & restore → Save backup**.
2. Install 0.9.0 and follow its two setup steps (turn it on, then choose it as your keyboard).
3. In the **new** app: **Backup & restore → restore** that file.
4. Uninstall the old app.

From now on, new versions install as normal updates over 0.9.0.

### Download: which APK do I need?
| Your phone | File |
|---|---|
| **Most phones from 2017 onward (64-bit)** | `jolpai-keyboard-0.9.0-arm64-v8a.apk` ⬅ pick this if unsure |
| Older 32-bit phones | `jolpai-keyboard-0.9.0-armeabi-v7a.apk` |
| Emulators / Chromebooks (Intel) | `…-x86_64.apk` or `…-x86.apk` |

Needs **Android 8.0 or newer**.

### New
- ✓ **Check suggests like the prediction strip**: a misspelling shows the fix **plus up to 2 other likely words** to tap (`takl → tail · or tall · talk`). Words you usually type after the previous word come first, and Jolpai remembers the word you pick. On public misspelling lists the right word is now offered **95.8 %** of the time (the single fix alone: 90 %)
- 🐞 Check no longer misses a misspelt **last word** (the "add a full stop" suggestion used to hide it)
- ℹ️ **New About page**: app header card, **Check for updates** (asks GitHub only when you tap and offers the APK for your phone), **What's new**, **Report a problem** (opens a GitHub issue with your app, Android and phone details, never anything you typed) and **Share Jolpai**
- 🏷️ The app's internal name is now `com.yeamin.jolpai` everywhere (Android settings, storage), matching its name

### Notes
- Still a **beta**, used daily on a Pixel 7 Pro. Please report problems in [Issues](https://github.com/Yeamin-Talukder/jolpai-keyboard/issues) or with **About → Report a problem**.
- Built and signed by GitHub Actions from the tagged source, with the same release key as before; checksums are in `SHA256SUMS.txt`.
