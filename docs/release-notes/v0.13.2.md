## Jolpai Keyboard 0.13.2 beta: "Choose keyboard" works on vivo and similar phones ⌨️

### Fixed
- ⌨️ **"Choose keyboard" now always does something.** Some phones (first seen on a vivo X200 Pro mini
  with OriginOS 6) silently ignore an app's request to open Android's keyboard chooser, so the setup
  button did nothing. Now, if the chooser doesn't appear within a second, Jolpai opens the phone's
  keyboard settings instead, with a hint to choose **Jolpai Keyboard** there. Phones where the
  chooser works (e.g. Pixels) behave exactly as before.
- 🔓 **"Open settings" for app updates always opens something.** Where a phone has no per-app
  "Install unknown apps" page, Jolpai now opens the list of apps, its app info, or security settings
  instead of doing nothing.
- 🛡️ **No more silent or crashing buttons for other system screens**: Keyboard settings, the
  microphone permission page and opening the app from the keyboard fall back to Settings on phones
  that leave those screens out. The keyboard-chooser key switches to the next keyboard if a phone
  refuses the chooser, and links say so when no browser is installed.

### Updating
- **From 0.10.0 or later:** About → **Update**, or download the APK below and open it; it installs as an
  update and keeps your data.
- **From 0.9.0:** download the APK below and open it.
- **From 0.7.0 or 0.8.0:** the app ID changed in 0.9.0, so move your data once: in the old app
  **Backup & restore → Save backup**, install 0.13.2, restore the file there, then uninstall the old app.
