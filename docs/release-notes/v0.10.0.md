## Jolpai Keyboard 0.10.0 beta: update without leaving the app 🫒

### New
- ⬇️ **Update right inside Jolpai.** About → **Update** downloads the new version with a progress ring
  (percent, size, speed, time left, Cancel) and installs it after Android's own "Update this app?" prompt.
  No more trips to GitHub. The first time, Android asks you to allow Jolpai to install apps; turn on
  "Allow from this source" and come back, and the update carries on by itself.
- 🛡️ **Every update is checked before it installs**: the download must match the release's SHA-256 checksum,
  and it must be Jolpai, newer than what you have, and signed with the same key. Otherwise nothing is installed.

### Updating to 0.10.0
- **From 0.9.0:** download the APK below and open it; it installs as an update and keeps all your data.
  (0.9.0 still opens GitHub for updates. From 0.10.0 on, updates happen inside the app.)
- **From 0.7.0 or 0.8.0:** the app ID changed in 0.9.0 (`com.yeamin.lipi` → `com.yeamin.jolpai`), so move your
  data once: in the old app **Backup & restore → Save backup**, install 0.10.0, restore the file there, then
  uninstall the old app.

### Download: which APK do I need?
| Your phone | File |
|---|---|
| **Most phones from 2017 onward (64-bit)** | `jolpai-keyboard-0.10.0-arm64-v8a.apk` ⬅ pick this if unsure |

Needs **Android 8.0 or newer**.

### Privacy
The app goes online for updates only when you tap **Check for updates** or **Update**, and only to GitHub.
Nothing you type is ever sent. The new "install apps" permission is used only for Jolpai's own update, and
Android asks you to confirm every install. See the [privacy policy](https://github.com/Yeamin-Talukder/jolpai-keyboard/blob/main/docs/PRIVACY.md).

### Notes
- Still a **beta**, used daily on a Pixel 7 Pro. Please report problems in [Issues](https://github.com/Yeamin-Talukder/jolpai-keyboard/issues) or with **About → Report a problem**.
- Built and signed by GitHub Actions from the tagged source, with the same release key as before; checksums are in `SHA256SUMS.txt`.
