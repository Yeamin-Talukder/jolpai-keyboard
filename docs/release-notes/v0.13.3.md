## Jolpai Keyboard 0.13.3 beta: the keyboard chooser lists your keyboards on vivo ⌨️

### Fixed
- ⌨️ **Empty "Select input method" list on vivo.** On a vivo X200 Pro mini (OriginOS 6, Android 16)
  **Choose keyboard** opened the chooser, but with no keyboards in it. Some phones build that list
  from the keyboard connected to a text field, and the setup screen had none focused. Jolpai now
  focuses an invisible text field first (without showing a keyboard), then opens the chooser.
- 🔗 **A backup link under Choose keyboard**: *List empty? Set it in keyboard settings* opens the
  phone's keyboard settings, where you can pick Jolpai as the current keyboard.

### Updating
- **From 0.10.0 or later:** About → **Update**, or download the APK below and open it; it installs as an
  update and keeps your data.
- **From 0.9.0:** download the APK below and open it.
- **From 0.7.0 or 0.8.0:** the app ID changed in 0.9.0, so move your data once: in the old app
  **Backup & restore → Save backup**, install 0.13.3, restore the file there, then uninstall the old app.
