## Jolpai Keyboard 0.13.0 beta: a new logo, and a launch animation 🫒

### New
- 🫒 **A new logo.** Jolpai's mark is now a keyboard with an olive (জলপাই) as the lit key and a leaf,
  in dark ink on an olive tile. It's the same mark as Jolpai Type. Android 13+ themed icons get a
  one-colour version that follows your wallpaper.
- ✨ **A launch animation** (Android 12 and newer). When you open the app the mark pops in, the leaf
  grows and waves, the keys tap like someone typing and the olive key is pressed last. It takes about
  a second, then the app opens.
- 🌱 **A living logo on the About page**: the keys keep tapping, the leaf sways and the olive key is
  pressed now and then. It stays still when the phone's animations are turned off.

### Updating
- **From 0.10.0 or later:** About → **Update**, or download the APK below and open it; it installs as an
  update and keeps your data.
- **From 0.9.0:** download the APK below and open it.
- **From 0.7.0 or 0.8.0:** the app ID changed in 0.9.0, so move your data once: in the old app
  **Backup & restore → Save backup**, install 0.13.0, restore the file there, then uninstall the old app.

### Notes
- Still a **beta**, used daily on a Pixel 7 Pro. Please report problems in [Issues](https://github.com/Yeamin-Talukder/jolpai-keyboard/issues) or with **About → Report a problem**.
- Some launchers keep showing the old icon until they refresh; restarting the phone or the launcher fixes it.
- On Android 8–11 there's no launch animation; the app opens straight away as before.
- Built and signed by GitHub Actions from the tagged source, with the same release key as before; checksums are in `SHA256SUMS.txt`.
