## Jolpai Keyboard 0.10.1 beta: a fix for Check for updates 🫒

### Fixed
- 🔄 **Check for updates works even when GitHub is limiting requests.** GitHub allows only 60 update checks an
  hour per internet connection without an account (shared by everyone on the same Wi-Fi). When that ran out,
  0.10.0 said "Couldn't reach GitHub. Check the internet", even though the internet was fine. Jolpai now finds
  the new version another way, with the same checksum and signature checks before it installs.
- 💬 **Clearer messages**: no connection, GitHub not answering, and a failed download each say what happened.

### Updating
- **From 0.10.0:** About → **Update**. If it says it couldn't reach GitHub, try again after a while, or download
  the APK below and open it; it installs as an update and keeps your data.
- **From 0.9.0:** download the APK below and open it; it updates in place. After this, updates happen inside the app.
- **From 0.7.0 or 0.8.0:** the app ID changed in 0.9.0, so move your data once: in the old app
  **Backup & restore → Save backup**, install 0.10.1, restore the file there, then uninstall the old app.
